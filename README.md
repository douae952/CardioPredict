# 🫀 CardioPredict

## Description
CardioPredict is a Machine Learning project designed to predict cardiovascular disease using the XGBoost classification algorithm.

## Technologies
- Python
- Pandas & NumPy
- Scikit-learn
- XGBoost
- Streamlit
- Joblib

## Project Workflow
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Data Visualization
4. Feature Selection (X / y)
5. Train-Test Split
6. Machine Learning Model Training
7. Model Evaluation
8. Model Saving using Joblib
9. Web Application Development using Streamlit

## Machine Learning Model
XGBoost Classifier.

## Run the Application

```bash
pip install -r requirements.txt
streamlit run app.py
```
